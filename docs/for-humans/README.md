# For humans

Summaries written for the human to read. They say what is true, not how it
is done.

## What belongs here

Content that is:

- **High density:** only the facts that matter, nothing repeated from elsewhere.
- **Not operational:** no procedures, commands or steps.
- **Stable:** no version numbers, code names or details that change with the
  implementation.
- **Targeted:** each file answers one question.

## Changes

- Every change is discussed with the human first: edits, new files and
  deletions.
- Files change rarely. A code or design change does not update them on its own.
  When one becomes stale, point it out and propose wording.
- Design docs under `docs/` remain the reference for how things work.
