# /help

Show the room's commands and keyboard controls.

```text
/help
```

The help listing starts with:

Recorded excerpt ([source](examples/terminal.txt)). `❯` marks user input.

```text
❯ /help

[help]
```

Help is displayed in the room transcript. You can use it while agents work.
Use PgUp and PgDn to scroll, or Ctrl+O to focus history.

The [manual index](index.md) links to examples and behavior for each command.
